# Dara Massalik - Angular General Dahira MVP

Frontend-only MVP for the general management of the Dahira.

## Stack
- Angular 20.3.x
- PrimeNG 20+
- Tailwind CSS 4
- NgRx Signal Store
- PWA / responsive UI

## General areas
- Dashboard
- Members
- Activities
- Commissions
- Quranic school
- Shop
- Finance

## Shop customer journey
- Product catalogue
- Category filtering
- Product detail page
- Add to cart
- Persistent cart with Signal Store + localStorage
- Cart quantity management
- Payment deliberately left out for the next iteration

## Run
```bash
npm install
npm start
```
